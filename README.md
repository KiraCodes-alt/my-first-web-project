# Freedom of the Media – Web Standards Project

An academic web page exploring the concepts of media freedom, international legal protections (such as the UDHR and the European Media Freedom Act), and tiered content protection in digital societies.

## Technologies Used
* **HTML5:** Semantic markup, structured article sections, figures, and definitions (`<abbr>`).
* **CSS3:** Custom layout styling via `styles.css`.
